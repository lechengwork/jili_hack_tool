## 萃取方法(決定性)
遊戲把每筆解密後回應存成 JSON 快取在 renderer heap:
`{"type":N,"ret":0,"error_msg":"","data":[<原始 protobuf bytes>]}`
→ Frida 全 dump renderer heap(不設 size 上限)→ 離線 grep `{"type":` → `data` 陣列即解密明文 protobuf。
持久、可靠、繞過加密、不用破 crypto、不用 V8 指標回溯。
