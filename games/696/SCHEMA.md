## type:0 = spin 結果
頂層:
- f1  (msg)   = 局面明細(見下)
- f2  (bytes) = 空(用途未定)
- f3  (f64)   = 總中獎金額。**win=0 時整個欄位省略**(protobuf 省略零值)
- f6  (f64)   = 玩家餘額(spin 後)
- f20 (varint)= 單號(顯示才加 `-`,如 2393330832000810696 → 23933-308320-00810696)
- f23 (msg)   = 下注資訊:
    - f1 (f64) = base 下注額(=0.3;**額外下注時這裡仍是 0.3,不是 0.45**)
    - f25 (bytes,空) = 固定出現
    - **f26 = 額外下注/ante。存在=有開;內層 f1=級別索引**
        - 無 f26        → 沒開額外下注
        - f26={}(空)   → 1.5倍額外下注(f26.f1=0 被省略)
        - f26={f1:1}    → 8倍額外下注
      (內層 f1.f18 也跟著:1.5倍=1, 8倍=2,疑似關聯倍率模式)

f1 局面明細(msg):
- f1[] (msg)  = 各 reel 資料(每筆 f1 = 3~5 bytes 符號)
- f2  (msg)   = 盤面符號窗,f1=bytes(如 [11,9,10,9,9,11,9,9,12,20] / [12,11,10,14,9])
- f6[] (msg)  = 中獎線,每條 { f1, f2, f3=線號, f4 f64=該線最終中獎(**已含 f12 倍率**) }。**沒中則整個省略**
- f7  (varint)= 中獎線數
- f12 (f64)   = **倍率(multiplier)**,nudge 後的最終總倍率(驗證:沒中=2.0對應輪面2x、20倍中獎=20.0)。單線最終分=base線分×f12
- f13 (f64)   = 總中獎(同頂層 f3)。**沒中省略**
- f15 (f64)   = 0.97(固定?RTP 相關?)
- f19[] (msg) = 更多盤面/符號狀態
- f8  (bytes) = 5 bytes(疑似 5 軸 nudge/倍率位置,如 [0,14,0,0,0])
- f18 (varint)= 額外下注級別(鏡射 f23.f26:1.5倍=1, 8倍=2;沒開=省略)
